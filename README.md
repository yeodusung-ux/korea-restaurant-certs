# 전국 맛집 인증 통합 조회

정부·공공기관이 각각 운영하는 **음식점 인증 4종**을 한 화면에서 지역·음식유형으로 찾아보는 도구입니다.
페이지 하나로 끝나며 서버가 없습니다(정적 HTML).

👉 **https://yeodusung-ux.github.io/korea-restaurant-certs/**

| 인증 | 무엇을 보증하나 | 소관 |
|---|---|---|
| 모범음식점 | 위생 | 행정안전부 |
| 착한가격업소 | 가격(메뉴·가격 공개) | 행정안전부 |
| 백년가게 | 업력(오래된 점포) | 소상공인시장진흥공단 |
| 안심식당 | 방역·위생 수칙 | 농림축산식품부 |

## 기능

- 시도 → 시군구 연동 필터, 음식 대분류 10종, 원본 분류, 통합검색(업소명·주소·메뉴)
- **인증 교집합** — 켜 놓은 인증을 *모두* 받은 곳만 보기. 한 가게는 한 줄로 접히고 인증 배지가 전부 표시됩니다
- 지역 × 음식유형 교차표(숫자 클릭 → 해당 목록)
- 결과 CSV 내보내기 · 주소 클릭 시 지도 검색 · 폰 대응(카드 레이아웃)

## 자동 갱신

`.github/workflows/update.yml` 이 **매주 일요일 04:00(KST)** 에 원본을 다시 받아 `index.html` 을 새로 만듭니다.
데이터가 그대로면 커밋하지 않습니다. Actions 탭에서 수동 실행(`Run workflow`)도 됩니다.

### 필요한 시크릿 2개

리포 **Settings → Secrets and variables → Actions → New repository secret**

| 이름 | 발급처 | 쓰이는 곳 |
|---|---|---|
| `ODCLOUD_KEY` | [공공데이터포털](https://www.data.go.kr) 일반 인증키(Decoding) | 백년가게 |
| `MAFRA_KEY` | [농림축산식품 공공데이터 포털](https://data.mafra.go.kr) — 가입 시 자동 발급 | 안심식당 |

> ⚠️ data.go.kr 개발계정 키는 **1년 만료**입니다. 만료되면 워크플로가 실패하며 메일로 알려줍니다.

### 실패하면 사이트는 어떻게 되나

**직전 정상본이 그대로 유지됩니다.** 빌드 스크립트는 소스별 최소 건수를 검사해
하나라도 미달이면 예외를 던지고 `index.html` 을 건드리지 않습니다.
한 소스가 조용히 비어 수만 건이 사라진 페이지가 배포되는 것을 막기 위한 장치입니다.

## 로컬에서 돌려보기

```bash
export ODCLOUD_KEY=...
export MAFRA_KEY=...
python build/build_site.py      # → index.html 생성 (약 2분)
```

의존성 없음(파이썬 표준 라이브러리만). Python 3.8 이상.

## 구조

```
index.html                     생성물. Pages 가 이걸 서빙한다
build/build_site.py            수집 → 정규화 → 매칭 → 페이지 생성
build/template.html            페이지 뼈대(/*__DATA__*/ 자리에 데이터가 박힌다)
build/baengnyeon_2022.csv      백년가게 2022 파일본(업종·연락처 이식용, 더 갱신되지 않음)
.github/workflows/update.yml   주간 갱신
```

## 데이터를 다루며 알게 된 것

원본 4종은 분류 체계도 지역 표기도 제각각이라 그대로 합칠 수 없었습니다. 코드에 반영된 보정들:

- **착한가격업소 다운로드 주소가 갱신마다 바뀝니다.** `atchFileId` 가 파일 버전에 묶여 있어
  매번 데이터셋 페이지에서 새로 찾습니다. 고정 URL로 박아두면 분기 갱신 때 옛 파일을 받습니다.
- **안심식당 `RELAX_SI_NM` 은 시도, `RELAX_SIDO_NM` 은 시군구**입니다(이름과 반대).
  `USE_YN` 에는 `Y`/`N` 말고 `여` 가 5건 섞여 있어 유효로 처리합니다.
- **시군구 세밀도가 달랐습니다.** `성남시 분당구`(모범음식점·백년가게) vs `성남시`(나머지) 라
  그대로 두면 교차 조회가 갈라집니다 → **시/군 레벨로 통일**. 구 단위는 검색으로 좁힙니다.
- **`전남광주통합특별시`** 표기는 시군구를 보고 광주광역시/전라남도로 되분리합니다.
- **백년가게 최신 API본은 컬럼이 4개뿐이고 연락처가 전량 비어** 있어, 2022 파일본에서
  업종·연락처를 이식합니다(약 75% 매칭). 이때 **시도·시군구가 맞을 때만** 붙입니다 —
  이름만 보고 붙이면 서울 가게에 지방 가게 정보가 들어갑니다.
- **대분류는 추정값**입니다. 안심식당(6종)·착한가격업소(11종)는 원본이 열거형이라 그대로 매핑하지만,
  모범음식점(233종)·백년가게(782종)는 자유입력이라 키워드 규칙을 씁니다. 원본 값은 항상 별도 열로 남깁니다.
- **동일 가게 매칭**(교집합 기능)은 근거가 강한 둘만 씁니다 — ① 전화번호 ② 시군구+도로명+건물번호 **AND 상호 유사**.
  `시군구+상호` 만으로 묶으면 동명이점(진미식당·김밥천국)이 한 가게가 됩니다.
